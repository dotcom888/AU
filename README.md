## 🌟 项目简介

整体采用**极简赛博暗色系（Cyber Minimal Dark）**与**清爽浅色系（Light Mode）**双主题设计，核心呈现一个会「注视」用户且拥有自主生命感的赛博小生命——**「小灵」**。

主界面分为左右两栏沉浸式交互架构：

- **左侧：伴侣小生命核心互动画布（Main Viewport）**
  - **灵动赛博生命体**：基于纯 SVG 矢量引擎驱动，小生命的一双眼睛会实时跟随用户的鼠标指针进行**平滑视线注视追踪（Gaze Tracking）**，并伴随温和的上下浮动、地面自适应投影呼吸及点击弹跳旋转反馈。
  - **4 种截然不同的情绪与动作状态**：
    - `ST_IDLE_01` **待机呼吸 (Idle)**：常态低频心跳脉冲（3.6s 周期），双眼自然注视与眨眼，环绕赛博青色呼吸氛围光晕。
    - `ST_HAPPY_02` **开心雀跃 (Happy)**：神经突触超频共振（1.2s 周期），弧形笑眼弯弯，环绕明快量子金环境流光。
    - `ST_SHY_03` **委屈/害羞 (Shy)**：磁通量微缩回避（2.4s 周期），眼神低垂回避，环绕电光粉环境光晕。
    - `ST_SLEEP_04` **犯困打瞌睡 (Sleepy)**：待机功耗下调（5.2s 周期），眼睑闭合横线，释放低频深空蓝休眠光波。
  - **动态呼吸渐变光晕（CSS Ambient Aura）**：多层径向流光与情绪、环境主题色丝滑平滑过渡（0.8s cubic-bezier 缓动），杜绝冷冰冰的传统聊天界面。
  - **多模态对话与快捷交互栏**：
    - 底部提供 1 个支持回车发送的文本输入框，内置扩展高拟真本地语义路由器；
    - 3 个高质感毛玻璃快捷互动按钮：`[摸摸头]`（触发害羞反应）、`[夸夸它]`（触发开心雀跃）、`[哄它睡觉]`（触发犯困休眠）；
    - 支持直接点击伴侣角色触发触觉弹跳与自旋反馈。

- **右侧：可折叠开发者调试面板（Remote Telemetry & Debug Console）**
  - **实时状态监控**：实时展示当前状态码（`ST_IDLE_01`、`ST_HAPPY_02`、`ST_SHY_03`、`ST_SLEEP_04`）、动作模式中文名称及拟真状态机运行描述。
  - **手动调试开关**：
    - 情绪强制切换：一键强制角色执行待机、开心、害羞或犯困动作；
    - 场景灯光主题色：独立切换赛博青、黄色、粉紫色、深蓝色环境光，或恢复自动联动；
    - 系统广播注入：向主视图动态注入开发者系统提示气泡（HUD Banner）。
  - **交互历史日志**：包含毫秒级时间戳、事件分类标签（`[USER_INPUT]`、`[QUICK_ACTION]`、`[OVERRIDE]`、`[SYSTEM]`、`[AMBIENT]`）与正文，支持一键清空日志。
  - **全局深浅色切换与折叠抽屉**：支持一键切换白天浅色/暗黑深色模式；支持随时平滑收起侧边栏，折叠后在边缘常驻毛玻璃触发标签，保障沉浸感。

## 🛠️ 技术栈与工程架构

- **核心框架**：Vue 3.5 (`<script setup lang="ts">` + Composition API)
- **开发语言**：TypeScript 6.x（严格模式，全类型推导，无类型隐患）
- **构建工具**：Vite 8.x + Rollup（秒级极速热重载，生产打包耗时仅 ~400ms）
- **UI & 动效方案**：
  - 纯 SVG 矢量几何与逐点形变引擎（零第三方模型体积负担）
  - 现代化 Scoped CSS、CSS 变量系统、Glassmorphism 玻璃拟态
  - CSS Keyframes 呼吸动效与立体阴影缩放
- **图标库**：`lucide-vue-next`
- **状态管理**：基于组合式函数 `usePetState.ts` 集中管理状态路由、情绪计时器、日志栈与主题联动

## 🚀 快速启动

### 1. 安装依赖
本项目推荐使用 `pnpm`（或 `npm` / `yarn`）：
```bash
pnpm install
```

### 2. 启动本地开发服务
```bash
pnpm dev
```
启动后在浏览器打开终端提示的地址（如 `http://localhost:5173/`）即可体验。

### 3. 生产打包与预览
```bash
# 执行 TypeScript 类型校验与构建
pnpm build

# 本地预览打包产物
pnpm preview
```

## 📝 交付物开发复盘

### ① 使用了哪些 AI 工具、实际耗时多久？
- **使用工具**：codex、谷歌Gemini
- **实际耗时**：约 **3小时**（包含技术选型、SVG图形、多层呼吸光晕与微动效调优、双主题暗/浅色调校）。

### ② 生成过程中 AI 原本写的哪个细节不够好，是你发现并手动要求它改掉的？

1. **背景渐变光晕在情绪切换时的色彩断层与生硬闪烁**：
   - *初始问题*：初始生成的背景渐变光晕直接在单层 `radial-gradient` 上通过 CSS class 切换，不仅颜色变换出现明显闪烁和色彩断层，且缺乏陪伴型生命的“温和呼吸韵律”。
   - *手动改动*：重构 `CyberBackground.vue`，提取 CSS 自定义变量系统（`--ambient-core`, `--ambient-outer`），赋予其 `transition: background 0.8s cubic-bezier(0.4, 0, 0.2, 1)`，并叠加左右两个不同频次的漂浮微流光动画（`ambientFloat`），让背景光影随小灵的情绪演进呈现如水彩晕染般的丝滑平滑呼吸感。

2. **角色缺乏交互灵魂（从呆板静态几何体到实时眼球注视追踪）**：
   - *初始问题*：AI 最初绘制的纯 CSS 球体只是一个居中浮动的静态几何圆球，交互时仅有僵硬的位移动画，毫无具身智能伴侣机器人应有的“生命感”与对主人的关注意识。
   - *手动改动*：为伴侣小生命接入了纯 SVG 驱动的实时视线追踪机制，在全局监听鼠标位置并换算出相对于小灵中心的归一化向量（`-1.0 ~ 1.0`），实时驱动眼睛的球面弧度偏移；同时融入了眨眼、待机微颤与点击弹跳自旋，真正让小灵具备了“看着你、听你倾诉”的鲜活性。
